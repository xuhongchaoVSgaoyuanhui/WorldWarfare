# Sage Documents

This folder contains documents that Sage can access and reference.

## How to Use

1. Place any documents you want Sage to know about in this folder
2. Supported file types: .md, .txt, .json, .xml, .html, .csv
3. Documents will be automatically synced to the Saved folder
4. Sage can list and read these documents through the 'list_docs' and 'get_doc_contents' commands

## Examples

- Project documentation
- API references
- Code style guides
- Requirements documents
- Any other reference material you want Sage to access
